# Changelog

All notable changes follow Keep a Changelog. This project uses Semantic Versioning.

## [0.1.1] - 2026-09-06

### Fixed

- Replaced device-metrics emulation with Chromium's persisted native desktop
  page zoom setting, using a lightweight DevTools client instead of the
  memory-heavy browser binding.
- Added a packaged `zoomcheck demo` command, claim checks, a clean-consumer
  package check, and a one-click static sample page.

## [0.1.0] - 2026-08-28

### Added

- Keyboard workflow recorder and high-zoom Chromium replay.
- Local HTML and JSON evidence reports for 200% and 400% zoom.
- Static installation, usage, privacy, and methodology documentation.
