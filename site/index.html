Record a path once, then keep one report for each selected zoom level.

Build from source

cargo install --path crates/zoomcheck

Run the bundled sample

zoomcheck demo

The sample writes its own temporary folder and reports known blocked controls. It exits 1 because those findings are intentional.

Record and replay your path

zoomcheck record https://app.example.test/cart \
  --name "Complete checkout" \
  --out .zoomcheck/checkout.json

zoomcheck check .zoomcheck/checkout.json \
  --out artifacts/zoomcheck

Checks after every key

Find blocked focus stops

Static audits do not replay a task. This runner collects geometry and focus evidence after each key.

A

Order and name

Checks whether focus reached the expected control and whether that control has a name.

B

Focus indicator

Records whether the focused control has an outline or box-shadow treatment.

C

Clipping and cover

Checks the viewport, overflow ancestors, and sampled points over the focused control.

D

Scroll path

Records whether the document or a containing region can scroll to expose focus.

Limits and privacy

What this tool does not do

It does not certify WCAG conformance or replace manual testing. It does not upload reports. Review local screenshots before sharing them because they can contain sensitive interface content.
