Plain-language policy

Privacy

Effective 28 August 2026

The short version

The CLI has no account, analytics, telemetry, advertising, or cloud report service. Workflow files, page details, and screenshots are written only to the output path you choose.

Website

This static documentation site does not set analytics cookies or send page content to third-party scripts. Its service worker stores the public documentation and illustration in your browser cache so the guide works offline. Clear the site’s stored data in your browser to remove that cache.

CLI evidence

A report can contain URLs, accessible names, layout measurements, and screenshots from the pages you test. Those files may be sensitive even though the tool does not upload them. Keep them in access-controlled CI artifacts, review them before sharing, and delete them according to your project’s retention policy.

Network requests

Chromium visits the workflow URL you provide and therefore makes the requests that page normally makes. Zoom Workflow Check itself does not add tracking or contact a Zoom Workflow Check server.

Questions

Open an issue in the source repository without including private screenshots or customer data.
